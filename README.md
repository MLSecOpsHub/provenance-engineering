# Provenance Engineering

> The open knowledge base for Provenance Engineering in software systems.


## What is provenance?

NIST defines provenance as:

> “The chronology of the origin, development, ownership, location, and changes to a system or system component and associated data.”

— [NIST, *Provenance — CSRC Glossary*](https://csrc.nist.gov/glossary/term/Provenance)

W3C PROV provides a broader, domain-independent definition:

> “Provenance is information about entities, activities, and people involved in producing a piece of data or thing.”

— [W3C, *PROV Family of Documents*](https://www.w3.org/TR/prov-overview/)


## Provenance Engineering

**Provenance Engineering** is the discipline of designing systems that capture,
preserve, verify and query the origins, identity, dependencies, transformations, authority
and causal history behind digital artifacts and automated decisions.
